# 도서기록 - 모바일 앱 디자인 계획

## 앱 개요
도서 대여, 소개, 추천 기능을 갖춘 독서 문화 앱. 사용자가 도서를 탐색하고, 대여 신청하며, 리뷰와 추천을 통해 독서 커뮤니티를 형성할 수 있다.

## 화면 목록

### 탭 네비게이션 (하단 탭 바)
1. **홈 (Home)** — 추천 도서, 신착 도서, 인기 도서
2. **탐색 (Explore)** — 도서 검색 및 카테고리 필터
3. **대여 (Rental)** — 대여 신청 현황 및 반납 관리
4. **커뮤니티 (Community)** — 독서 리뷰, 추천 피드
5. **마이 (My)** — 독서 기록, 찜 목록, 프로필

### 모달/스택 화면
- **도서 상세 (BookDetail)** — 도서 정보, 대여 버튼, 리뷰 목록
- **리뷰 작성 (WriteReview)** — 별점 + 텍스트 리뷰 입력
- **도서 추천 (RecommendBook)** — 친구/커뮤니티에 도서 추천

## 화면별 상세 설계

### 1. 홈 화면 (Home)
**주요 콘텐츠:**
- 상단: 앱 로고 + 검색 아이콘
- 배너: 이달의 추천 도서 (가로 스크롤 카드)
- 섹션: "신착 도서" (가로 스크롤 소형 카드)
- 섹션: "인기 도서 TOP 10" (세로 리스트)
- 섹션: "장르별 추천" (카테고리 칩)

**기능:** 도서 탭 → 상세 화면 이동, 검색 아이콘 → 탐색 탭

### 2. 탐색 화면 (Explore)
**주요 콘텐츠:**
- 검색 바 (상단 고정)
- 장르 카테고리 칩 (소설, 에세이, 자기계발, 과학, 역사, 어린이 등)
- 검색 결과 / 카테고리 필터 결과 그리드

**기능:** 실시간 검색, 카테고리 필터, 정렬 옵션 (인기순/최신순/평점순)

### 3. 대여 화면 (Rental)
**주요 콘텐츠:**
- 탭: "대여 중" / "대여 이력"
- 대여 중 도서 카드 (반납 기한 D-day 표시)
- 대여 이력 리스트

**기능:** 반납 신청, 연장 신청, 대여 이력 조회

### 4. 커뮤니티 화면 (Community)
**주요 콘텐츠:**
- 탭: "추천 피드" / "리뷰"
- 추천 카드 (추천인, 도서 정보, 추천 이유)
- 리뷰 리스트 (별점, 한줄평)

**기능:** 추천 작성, 리뷰 작성, 좋아요

### 5. 마이 화면 (My)
**주요 콘텐츠:**
- 프로필 섹션 (닉네임, 독서 통계)
- 독서 통계 카드 (이번 달 읽은 책, 총 대여 횟수)
- 찜한 도서 목록
- 내가 쓴 리뷰 목록
- 설정 메뉴

### 6. 도서 상세 화면 (BookDetail)
**주요 콘텐츠:**
- 도서 표지 이미지 (상단 히어로)
- 제목, 저자, 출판사, 장르
- 대여 가능 여부 배지
- 소개 텍스트 (접기/펼치기)
- 별점 평균 + 리뷰 목록
- 하단 고정: "대여 신청" 버튼

## 핵심 사용자 플로우

### 플로우 1: 도서 대여
홈 → 도서 탭 → 도서 상세 → "대여 신청" 버튼 → 확인 모달 → 대여 완료 → 대여 탭에서 확인

### 플로우 2: 도서 추천
커뮤니티 탭 → "추천 작성" → 도서 검색 → 추천 이유 입력 → 게시 → 피드에 표시

### 플로우 3: 리뷰 작성
도서 상세 → "리뷰 작성" → 별점 선택 → 텍스트 입력 → 저장 → 리뷰 목록에 표시

## 컴포넌트 설계

| 컴포넌트 | 설명 |
|---------|------|
| `BookCard` | 도서 표지 + 제목 + 저자 + 대여 상태 카드 |
| `BookListItem` | 세로 리스트용 도서 아이템 |
| `StarRating` | 별점 입력/표시 컴포넌트 |
| `ReviewCard` | 리뷰 카드 (닉네임, 별점, 텍스트) |
| `RecommendCard` | 추천 카드 (추천인, 도서, 이유) |
| `RentalCard` | 대여 중 도서 카드 (D-day 배지) |
| `CategoryChip` | 장르 필터 칩 |
| `SectionHeader` | 섹션 제목 + "더보기" 링크 |
